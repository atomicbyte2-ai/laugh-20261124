A single funny line for the make.fun "The One-Line Laugh" bounty: a joke about the gap between how hard banks work to protect our money and how easily one bad day undoes all of it, landing the surprise in the final words.

> My bank account has two-factor authentication, but my spending only needs one bad day.

## Run

```sh
npm start
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
